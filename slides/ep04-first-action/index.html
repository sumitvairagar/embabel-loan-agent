Your First @Action

An LLM call with typed input and typed output. No boilerplate.

The Container

@Agent — marks the class, Spring does the rest

@Agent(description = "Processes loan applications and produces a credit decision") class LoanApprovalAgent { // your @Action methods go here }
@Agent
Marks this as an agent. Spring auto-discovers it via classpath scan — same as @Controller.
description
Required. Used by the platform in open mode to match user intent to the right agent.
Spring bean
@Agent includes @Component. You can @Autowired any Spring service into this class.
The Action

@Action — declare what you need and what you produce

@Action fun evaluateCredit( application: LoanApplication, // ← framework reads FROM blackboard ai: Ai // ← framework injects (NOT from blackboard) ): CreditScore = // ← framework writes TO blackboard ai.withDefaultLlm() create """ Evaluate the credit profile for this loan application. Applicant: ${application.applicantName} Amount: ₹${application.amount} Purpose: ${application.purpose} Return: score (300–900), rating, and key factors. """.trimIndent()
Kotlin note: The triple-quoted """...""" is a multiline string — no concatenation, no escape characters needed. ${variable} inside it is string interpolation — like Java's formatted strings but cleaner.
Under the Hood

What happens when this action runs

1
Schema generation. Embabel reflects on CreditScore (your return type) and generates a JSON Schema from it — including your @JsonPropertyDescription hints.
2
Prompt assembly. Your prompt text + the JSON schema get combined into the final message sent to the LLM: "respond with JSON matching this schema."
3
LLM call. Spring AI makes the HTTP call to OpenAI. The response comes back as JSON.
4
Deserialization. Jackson parses the JSON into a CreditScore object. Your method returns a strongly-typed Kotlin object — not a Map, not a String.
Demo

Run it from the Spring Shell

shell:> execute "My name is Sumit, I need a home loan of 25 lakh" [extractApplication] UserInput → LoanApplication applicantName = "Sumit" amount = 2500000 purpose = "home" [evaluateCredit] LoanApplication → CreditScore score = 730 rating = "Good" factors = [stable employment, low existing debt]
The planner ran extractApplication first automatically — because evaluateCredit needs a LoanApplication and the only way to get one is to extract it from the user input first. You wrote zero ordering code.
