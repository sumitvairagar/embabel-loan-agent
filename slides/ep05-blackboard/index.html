The Blackboard

The agent's shared memory. How data flows between every step.

Concept

The Blackboard is an append-only ordered list

One blackboard per agent run. Every action reads from it and writes to it. Actions never pass data to each other directly — everything goes through the board.

Key Property

Append-only. Objects are never deleted.

If a fraud check re-evaluates credit and produces a new score, the old one stays — but becomes invisible to retrieval. The last one of each type wins.

after fraud check re-evaluation
[0]
UserInput
...
latest
[1]
CreditScore
score=730 — original
hidden
[2]
CreditScore
score=690 — after fraud check
latest
Why keep the old one? Full audit trail. You can always see what changed during a run and when. The Blackboard is append-only by design.

The Rule

Actions never touch the Blackboard directly

❌ You never write this
val app = blackboard
  .last(LoanApplication::class.java)

blackboard += creditScore
✅ You write this instead
@Action
fun evaluateCredit(
  application: LoanApplication, // read
  ai: Ai
): CreditScore = ... // write
Parameters = what you need from the Blackboard. Return type = what you add to the Blackboard. The framework handles all the reading and writing. You declare intent, not mechanics.
