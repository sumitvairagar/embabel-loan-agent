Unit Testing

Test your agent without calling a real LLM. Zero API cost. Zero network.

Why Test

AI agents need tests more than regular code

1
Prompts are code. If your prompt doesn't include the applicant's name, the LLM can't make a good decision. Test that the prompt contains what it should.
2
Regressions are invisible. A prompt change that looks harmless might silently degrade output quality. Tests catch this before it reaches production.
3
Fast feedback loop. Running a real LLM call costs money and takes seconds. Unit tests run in milliseconds, free, offline.
The Tool

FakeOperationContext — a fake Ai for tests

// Create a fake Ai that captures all LLM calls val context = FakeOperationContext() // Tell it what to return when createObject is called context.expectResponse(CreditScore(750, "Good", listOf("stable income"))) // Call the action directly — no Spring, no LLM, no network val application = LoanApplication("Sumit", 2500000, "home") agent.evaluateCredit(application, context) // ← context IS the Ai // Inspect what prompt was sent to the LLM val prompt = context.llmInvocations.first().prompt assertTrue(prompt.contains("Sumit")) assertTrue(prompt.contains("2500000"))
Test Structure

What to test in every action

Prompt content
Does the prompt contain the applicant's name? The loan amount? The credit score? If not, the LLM can't do its job.
No tool groups
Verify that pure LLM-transform actions don't accidentally request web search tools — that would add cost and latency.
LLM model choice
Does the action use the default model or request a specific one? Verify the hyperparameters are what you intended.
Key principle: You're not testing what the LLM returns. You're testing what you send to the LLM. That's in your control. The LLM's response is not.
Real Test

From the actual test file

class LoanApprovalAgentTest { private val agent = LoanApprovalAgent() @Nested inner class `evaluateCredit prompt` { @Test fun `must contain applicant name`() { val context = FakeOperationContext() context.expectResponse(CreditScore(750, "Good", listOf())) val application = LoanApplication("Sumit Vairagar", 2500000, "home") agent.evaluateCredit(application, context) val prompt = context.llmInvocations.first().prompt assertTrue(prompt.contains("Sumit Vairagar")) } } }
