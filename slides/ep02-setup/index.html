Episode 02

Project Setup

Spring Boot + Embabel running in under 5 minutes.

Prerequisites

What you need before we start

Java 21+
Check: java -version
Maven 3.9+
Check: mvn -version
OpenAI API Key
Set: export OPENAI_API_KEY=sk-...
IntelliJ IDEA
Community edition is fine
Clone the repo: git clone https://github.com/sumitvairagar/embabel-loan-agent
Then: git checkout ep02-setup
The pom.xml

Three dependencies. That's it.

<!-- Spring Boot parent provides Kotlin + Spring Boot versions --> <parent> <groupId>org.springframework.boot</groupId> <artifactId>spring-boot-starter-parent</artifactId> <version>3.4.5</version> </parent> <!-- Embabel BOM manages all Embabel versions --> <dependency> <groupId>com.embabel.agent</groupId> <artifactId>embabel-agent-starter</artifactId> <!-- core --> </dependency> <dependency> <artifactId>embabel-agent-starter-shell</artifactId> <!-- CLI --> </dependency> <dependency> <artifactId>embabel-agent-starter-openai</artifactId> <!-- OpenAI --> </dependency>
The Embabel BOM (Bill of Materials) manages all version numbers. You declare the BOM version once and all Embabel dependencies inherit it — no version conflicts.
Configuration

application.yml — minimal config

spring: ai: openai: api-key: ${OPENAI_API_KEY} # reads from environment variable chat: options: model: gpt-4o-mini # cheap and fast for dev embabel: agent: platform: log-prompts: false # set true to see full prompts log-responses: false # set true to see LLM responses logging: level: com.embabel: INFO com.engineerinai: INFO # our app logs
Never hardcode your API key. Use ${OPENAI_API_KEY} — reads the environment variable at startup. Add the key to your IntelliJ run configuration under Environment Variables.
Entry Point

The main class — standard Spring Boot

@SpringBootApplication class LoanAgentApplication fun main(args: Array<String>) { runApplication<LoanAgentApplication>(*args) } // That's the entire main class. // Embabel discovers your @Agent classes automatically // via Spring's classpath scanning — same as @Controller.
Kotlin note: *args is the spread operator. It expands an array into varargs — equivalent to Java's String... args. You'll see this pattern in every Spring Boot Kotlin app.
Run It

Start the shell — you should see this

$ mvn spring-boot:run . ____ _ __ _ _ /\\ / ___'_ __ _ _(_)_ __ __ _ \ \ \ \ ( ( )\___ | '_ | '_| | '_ \/ _` | \ \ \ \ :: Embabel Agent Platform :: Registered agent: LoanApprovalAgent Platform ready. 1 agent, 0 goals achieved so far. shell:> _
You're in the Spring Shell. Type help to see available commands. Next episode we add our first @Agent class and run it from here.
