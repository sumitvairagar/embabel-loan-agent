The Problem

Every AI tutorial is Python.
You are a Java developer.

LangChain, LlamaIndex, CrewAI — all Python. If you want to build AI agents on your existing Spring Boot codebase, you're told: learn Python first, then come back. That's wrong.

Python ecosystem
LangChain, LlamaIndex, CrewAI — great tools, wrong language for your stack
Spring AI alone
Great for single LLM calls. No planning. No sequencing. You write all the flow logic.
Embabel
Kotlin + Spring Boot. GOAP planning. Zero flow control code. Built for the JVM.
The Answer

Spring AI gives you the HTTP call.
Embabel gives you the brain.

LayerWhat it doesAnalogy
Spring AI Makes a single HTTP call to OpenAI / Anthropic / Gemini Servlet API
Embabel Plans which actions to run, in what order, using which model Spring MVC
Created by Rod Johnson — the same person who created the original Spring Framework in 2002. 4.5k GitHub stars. On Maven Central. This is not a weekend project.

Why Now

This is where Spring Boot was in 2013.

1
You become rare immediately. People who can implement Embabel in production Spring Boot number in the hundreds globally. Every bank and enterprise Java shop is about to need this.
2
Your existing knowledge carries over. @Agent works like @Controller. @Action works like @RequestMapping. Same Spring idioms, new capability.
3
You can contribute to open source today. The project is active. Issues are well-scoped. Maintainers review quickly. Your name in the contributor list is a career asset.
