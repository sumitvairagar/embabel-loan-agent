@AchievesGoal

The finish line. When this runs, the agent is done.

Concept

A Goal is the desired end state

The GOAP planner doesn't just run actions — it works toward a goal. A goal says: "we're done when this type of object exists on the Blackboard." Without a goal, the planner has nothing to work toward.

outputType
The type that must exist on the Blackboard when we're done — LoanDecision
description
Used in open mode — the platform matches user intent to goals by description
@AchievesGoal
Shortcut annotation — creates the Goal automatically from the method's return type
The Code

Two annotations. Complete agent.

@AchievesGoal(description = "Produce a final loan decision for the applicant") @Action fun generateDecision( application: LoanApplication, assessment: RiskAssessment, ai: Ai, ): LoanDecision = // ← when this hits the Blackboard, agent is done ai.withDefaultLlm() create """ Generate a final loan decision letter. Applicant: ${application.applicantName} Amount: ₹${application.amount} Risk: ${assessment.riskLevel}, approved=${assessment.approved} Write a clear decision, friendly message, and 2-3 next steps. """.trimIndent()
@AchievesGoal + @Action together = this method is both a step in the plan AND the finish line. When LoanDecision appears on the Blackboard, the OODA loop exits.
